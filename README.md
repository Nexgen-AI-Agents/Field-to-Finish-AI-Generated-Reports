## 🌐 Viewing Dashboards

Each report folder contains a self-contained HTML dashboard. To view:
1. **Clone or download** this repo
2. Open any `FTF_DASHBOARD_*.html` file directly in your browser
3. No server, no software, no login required

> Charts require an internet connection (Chart.js loads from CDN). All data is embedded in the HTML.

## 🔄 Regenerating Reports

Each folder contains a `REPORT_PROMPT.txt` with the exact prompt and SQL queries used to generate that report. To regenerate or create a new report:

1. Open Claude Code connected to `nexgen_ftf_db` (MySQL MCP)
2. Copy the standard prompt from `REPORT_PROMPT.txt`
3. Update the date range as needed
4. Claude queries the DB and outputs Excel + PDF + HTML dashboard + REPORT_BRIEF automatically

## ⚙️ Setup

```bash
cp .env.example .env
# Fill in your DB credentials in .env
```

The `.mcp.json` file configures the MySQL MCP server for Claude Code. Credentials are read from environment variables (never committed).
